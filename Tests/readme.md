## SUS usability survey

The SUS (System Usability Scale) survey can be used to evaluate usability quickly (Busquets, *Measuring usability with the System Usability Scale (SUS)*, n.d.). On a scale from 1 to 5, where 1 is “Strongly disagree” and 5 is “Strongly agree”, each item suggested by the survey was scored. The result is as follows:

![SUS survey result](image-3.png)

SUS score — Medical APP: **85**

According to the proposed scoring system, this is a high score (71–100): system usability is acceptable, though several improvements can still be made to reach excellence—especially ensuring that the modules work correctly and avoiding error reports that could have been anticipated.

## Areas for improvement

Based on the HEART model evaluation, the following opportunities for improvement are suggested:

* Optimize navigation with a more intuitive and accessible interface.
* Reduce cognitive load with simpler user flows and visual guidance.
* Add interactive assistance (chatbots, FAQs, live support).
* Increase accessibility options for users with visual and motor disabilities.
* Improve adoption with simplified onboarding and interactive tutorials.
